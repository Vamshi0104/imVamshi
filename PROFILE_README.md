## Engineering Profile

```txt
I care about:
  - systems that are observable before they are mysterious
  - APIs that make the right thing easy
  - performance wins that users and teams can actually feel
  - abstractions that remove real complexity
  - code that another engineer can trust at 2 AM

I avoid:
  - cleverness that hides behavior
  - dashboards with no operational truth
  - "works on my machine" engineering
  - fragile glue pretending to be architecture
```
